# api — серверная часть сайта

Отвечает: Дугарова А. Ревьюер: Селенкова Е.

FastAPI-приложение: отдаёт данные из базы в JSON (`/api/...`) и собирает страницы из шаблонов `web/`. В ВКонтакте не ходит никогда.

| Файл | Что в нём |
|---|---|
| `main.py` | Приложение FastAPI и маршруты |
| `schemas.py` | Формат ответов (модели pydantic) |

Запросы спринта 3 (подробно — в `docs/api.md`):
- `GET /api/events?category=&date_from=&date_to=&page=` — лента;
- `GET /api/events/{id}` — одно мероприятие, 404, если его нет;
- `GET /api/categories` — категории с числом мероприятий.

Запуск из корня репозитория: `uvicorn api.main:app --reload`. Описание API открывается на http://127.0.0.1:8000/docs.

Правила:
- Данные — только из базы, через модели `db/`.
- В ленту попадают только `published` и не прошедшие мероприятия, по порядку даты и времени.
- Имена полей — как в `docs/event_format.md`.
