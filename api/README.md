# api — серверная часть сайта

Отвечает: Дугарова А.

FastAPI-приложение: отдаёт данные из базы в JSON (`/api/...`) и раздаёт собранный фронтенд из `web/dist`. В ВКонтакте не ходит никогда.

| Файл          | Что в нём                                                                   |
| ------------- | --------------------------------------------------------------------------- |
| `main.py`     | Приложение FastAPI и запросы `/api/...`                                      |
| `schemas.py`  | Формат запросов и ответов (модели pydantic)                                  |
| `errors.py`   | Ошибки в одном формате и на русском: `422` со списком «поле — текст»         |
| `frontend.py` | Раздача `web/dist`: файлы сборки и `index.html` для `/event/12`, `/submit`, `/admin` |

Запросы (подробно — в [docs/api.md](../docs/api.md)):

- `GET /api/events?category=&date_from=&date_to=&q=&page=&per_page=` — лента, поиск, календарь;
- `GET /api/events/{id}` — одно мероприятие, 404, если его нет;
- `GET /api/categories` — категории с числом мероприятий;
- `POST /api/submissions` — заявка из формы «Подать мероприятие»;
- `GET /api/health` — API и база работают.

Запуск из корня репозитория:

```bash
python -m db.init_db             # таблицы, категории и сообщества
python -m db.seed_test           # тестовые мероприятия (только для разработки)
uvicorn api.main:app --reload    # http://127.0.0.1:8000/docs
python -m pytest tests/test_api.py tests/test_frontend.py
```

Правила:

- Данные — только из базы, через модели `db/`. API таблицы не создаёт.
- В ленту попадают только `published` мероприятия с датой и категорией, не прошедшие, по порядку даты и времени.
- Имена полей — как в `docs/event_format.md`. Поменяли ответ — обновите его и `docs/api.md` в том же PR.
