# collector — сбор и разбор объявлений

Отвечает: Шехина К. Ревьюер: Дугарова А.

Отдельная программа: раз в сутки забирает новые посты из сообществ ВК, сохраняет их в базу и извлекает из текста поля мероприятия. С сайтом она не связана — встречаются только в базе.

| Файл | Что в нём | Требование |
|---|---|---|
| `fetch.py` | Загрузка постов через `wall.get` в таблицу `vk_posts` | ФТ-01 |
| `extract.py` | Дата, время, место и категория из текста поста | ФТ-02, ФТ-03, ФТ-04 |
| `evaluate.py` | Сверка `extract.py` с `data/reference_50.csv`, результат — в `docs/extraction_check.md` | Р-04 |

Запуск из корня репозитория: `python -m collector.fetch`, `python -m collector.evaluate`.

Правила:
- Ключ VK берётся только из `.env` (`VK_SERVICE_TOKEN`) и никогда не пишется в код.
- В базу пишем через модели из `db/`, свои таблицы не создаём.
- Если дата не найдена, поле остаётся пустым, а дату публикации не подставляем.
- Закреплённый пост (`is_pinned`) пропускаем. Для репоста берём текст и ключ исходного поста из `copy_history`.
- Ошибка одного сообщества пишется в лог и не останавливает весь сбор.
