# data — эталонные данные

Отвечает: Шехина К.

| Файл               | Что в нём                                                                                                       |
| ------------------ | --------------------------------------------------------------------------------------------------------------- |
| `reference_50.csv` | 50 постов из ВК с вручную записанными правильными датой, временем, местом и категорией. По ним проверяется разбор: `python -m collector.evaluate`, результат — в [docs/extraction_check.md](../docs/extraction_check.md) |

Колонки `reference_50.csv`: `link`, `community`, `published_at` (день публикации `ГГГГ-ММ-ДД`), `text` (исходный текст поста целиком), `is_event` (да/нет), `event_date`, `end_date` (`ГГГГ-ММ-ДД`), `start_time` (`ЧЧ:ММ`), `location`, `category` (код из `docs/event_format.md`).

Правила разметки:

- Формат CSV в кодировке UTF-8, разделитель — запятая. В Excel: «Сохранить как» → «CSV UTF-8 (разделитель — запятая)».
- Записываем только то, что есть в тексте поста. Чего в тексте нет (только на картинке или «и так понятно») — оставляем пустым.
- Дата — день проведения, а не срок подачи заявки. Год — по дате публикации. У многоэтапного мероприятия — даты основного этапа.
- Время — по Томску: «15:00 по МСК» записываем как 19:00.
- Место онлайн — «Онлайн», даже если в посте написано «вебинар» или «дистанционно».
- `is_event = нет` — пост не про мероприятие (новость, услуга, итоги). Дату у такого поста не записываем.
- Для репоста берём текст исходного поста. Подписи интерфейса ВК («1/9», «Следующий слайд») в текст не попадают.
- Сюда не кладём файлы базы данных и личные данные людей: почту и телефон частного лица заменяем на `[почта]` и `[телефон]`.
