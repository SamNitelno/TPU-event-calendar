# data — эталонные данные

Отвечает: Шехина К.

| Файл               | Что в нём                                                                                                       |
| ------------------ | --------------------------------------------------------------------------------------------------------------- |
| `reference_50.csv` | 50 объявлений с вручную записанными правильными датой, временем, местом и категорией. По ним проверяется разбор |

Колонки `reference_50.csv`: `link`, `community`, `published_at`, `text` (исходный текст поста целиком), `is_event` (да/нет), `event_date`, `end_date` (`ГГГГ-ММ-ДД`), `start_time` (`ЧЧ:ММ`), `location`, `category` (код из `docs/event_format.md`).

Правила:

- Формат CSV в кодировке UTF-8. В Excel: «Сохранить как» → «CSV UTF-8 (разделитель — запятая)».
- Дата — день проведения, а не срок подачи заявки. Год — по дате публикации.
- Сюда не кладём файлы базы данных и личные данные людей.
