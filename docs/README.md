# Документация календаря ТПУ

Начните с [архитектуры](architecture.md). В ней собраны общая схема, стек, жизненный цикл мероприятия и путь заявки через фронтенд, API и базу.

| Документ | Что в нём |
|---|---|
| [architecture.md](architecture.md) | Компоненты, точки входа, связи, статусы событий и сценарий модерации |
| [design.md](design.md) | Маршруты React, модули, состояние экранов, даты Томска и связь с FastAPI |
| [api.md](api.md) | Публичные и административные запросы, фильтры, ошибки, вход и CSRF |
| [db_schema.md](db_schema.md) | ER-диаграмма семи таблиц, ключи, индексы, транзакции и инициализация |
| [collector.md](collector.md) | Поток VK → парсер → БД, дедупликация, автопубликация и ошибки |
| [deployment.md](deployment.md) | Vercel, Neon, GitHub Actions, окружения, переменные, CI и диагностика |
| [event_format.md](event_format.md) | Поля события, их обязательность, категории и пример JSON |
| [communities.md](communities.md) | Исходные сообщества ВК, `owner_id` и управление активностью |
| [extraction_check.md](extraction_check.md) | Повторяемый прогон парсера, исторические замеры и расхождения |

Диаграммы записаны в Mermaid и отображаются при просмотре Markdown на GitHub. Для первого локального запуска используйте [README проекта](../README.md). Команды и примеры рассчитаны на запуск из корня репозитория, если указанная инструкция не задаёт другую папку.

Схемы и контракты сверены 27.11.2026 с кодом `e6318af`. При изменении поведения обновляйте связанные схемы, примеры payload и ссылки на конфигурацию в том же PR.
