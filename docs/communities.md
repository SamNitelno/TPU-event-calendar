# Сообщества-источники

Из этих 15 сообществ сборщик получает посты через `wall.get`. Их добавляет `python -m db.init_db` из списка `COMMUNITIES` в [db/init_db.py](../db/init_db.py). Список сверяет [tests/test_db.py](../tests/test_db.py). Путь поста и обработка ошибок показаны в [карте сборщика](collector.md).

`owner_id` у сообщества отрицательный, по нему сборщик обращается к стене. Ссылка `https://vk.com/club<номер>` работает всегда, даже если у сообщества сменится короткий адрес.

## Как проверено

- 10.11.2026 стены всех 15 сообществ открывались без авторизации.
- 11.11.2026 сборщик успешно получил 450 постов через VK API, по 30 от каждого сообщества. Результаты сохранены в [отчёте по разбору](extraction_check.md#после-доработки-фт-01-11112026).
- 27.11.2026 GitHub зафиксировал успешный плановый сбор. Актуальные запуски и ошибки проверяются в логе workflow. [Запуск 27.11.2026](https://github.com/SamNitelno/TPU-event-calendar/actions/runs/45965178877)

В новой БД все 15 источников активны. В рабочей базе набор активных источников определяется полем `vk_communities.is_active`. Повторный `db.init_db` сохраняет выбранное значение. При ошибке сообщества сборщик переходит к следующему и отмечает проход как неуспешный.
