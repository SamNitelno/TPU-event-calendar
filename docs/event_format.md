# Формат мероприятия

Одна запись `events` может появиться после разбора ВК или после подачи заявки. [ER-диаграмма](db_schema.md) показывает ограничения хранения, а [контракт API](api.md) — публичное и административное представления.

## Поля записи

| Поле | Тип | Заполнение и видимость |
|---|---|---|
| `id` | Целое | Первичный ключ. Публичный ID карточки. |
| `post_id` | Целое или `null` | Внешний ключ на `vk_posts`, устанавливает сборщик. У заявки из формы пустой. |
| `category_id` | Целое или `null` | Внешний ключ на `categories`. При подаче заявки и публикации категория обязательна. В форме и модерации приходит `category` со slug, в ответах это объект `{slug, name}`. |
| `source` | `vk` или `form` | Способ появления записи. |
| `status` | `pending`, `published`, `rejected` | Заявка создаётся в `pending`. Сборщик публикует анонс ВК с однозначной датой и категорией, остальные анонсы направляет на проверку. Модератор может изменить статус в любом направлении. |
| `title` | Строка | Обязательное название. Сборщик берёт первую содержательную строку поста. |
| `description` | Текст или `null` | Очищенный текст ВК или описание из формы. Публично доступно на карточке. |
| `event_date` | `YYYY-MM-DD` или `null` | Первый день. Обязателен для заявки и публикации. |
| `end_date` | `YYYY-MM-DD` или `null` | Последний день многодневного мероприятия. При пустом значении последним днём считается `event_date`. |
| `start_time`, `end_time` | `HH:MM` или `null` | Местное время Томска. Пустое поле означает, что время неизвестно. |
| `location` | Строка или `null` | Адрес, площадка или значение «Онлайн». |
| `organizer` | Строка | Обязательный организатор. Для ВК — название сообщества, из которого пришла запись. |
| `original_post_link` | Ссылка или `null` | Сборщик заполняет ссылкой на исходный пост. В заявке и модерации URL необязателен, проверяются схема HTTP(S) и хост ВК. |
| `image_url` | Ссылка или `null` | URL крупнейшей фотографии из вложений ВК. Публично доступен на карточке. |
| `contact` | Строка или `null` | Контакт автора, обязателен в форме. Возвращается в приватных ответах админки. |
| `created_at` | Дата и время | Время вставки, задаётся БД. Используется для сортировки админской очереди. |

Лента и публичная карточка требуют `published`, известную дату и категорию. Поля `post_id`, `category_id`, `status`, `contact` и `created_at` отсутствуют в публичных ответах ленты и карточки. Ответ на создание заявки возвращает её `id` и `status`. Админка дополнительно возвращает `status` и `contact`, а дата и категория могут быть `null`.

## Категории

Начальный справочник заполняет [db.init_db](../db/init_db.py).

| Код | Название |
|---|---|
| `sport` | Спорт |
| `science` | Наука |
| `creativity` | Культура |
| `volunteering` | Волонтёрство |
| `career` | Карьера |
| `student_life` | Студенческая жизнь |

## Пример записи в ответе API

Фрагмент ответа `GET /api/events`:

```json
{
  "items": [
    {
      "id": 101,
      "title": "Мастер-класс по алтимату",
      "organizer": "Спортклуб «Сибирские львы»",
      "category": { "slug": "sport", "name": "Спорт" },
      "source": "vk",
      "event_date": "2026-12-06",
      "end_date": null,
      "start_time": "18:00",
      "end_time": null,
      "location": "ул. Карпова, 4",
      "original_post_link": "https://vk.com/wall-44845822_52494"
    }
  ],
  "page": 1,
  "per_page": 20,
  "total": 1
}
```

`GET /api/events/101` возвращает объект мероприятия с теми же полями плюс `description` и `image_url`. Формат входных данных и ошибки валидации описаны в [api.md](api.md).
