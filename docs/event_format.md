# Формат мероприятия

## Поля

| Поле                 | Тип                                | Обязательно        | Кто заполняет          | Пример и комментарий                                                   |
| -------------------- | ---------------------------------- | ------------------ | ---------------------- | ---------------------------------------------------------------------- |
| `id`                 | число                              | да                 | база                   | `101`                                                                  |
| `post_id`            | число                              | нет                | сборщик                | Ссылка на строку `vk_posts`. Пусто для заявок из формы                 |
| `category`           | код категории                      | да                 | сборщик или форма      | `sport`. В базе — `category_id`                                        |
| `source`             | `vk` или `form`                    | да                 | сборщик или форма      | Нужно для критерия «70% записей собраны автоматически»                 |
| `status`             | `pending`, `published`, `rejected` | да                 | сборщик, администратор | Пост ВК с найденной датой — `published`, заявка из формы — `pending`   |
| `title`              | строка                             | да                 | сборщик или форма      | `Мастер-класс по алтимату`. Для ВК — первая строка поста               |
| `description`        | текст                              | нет                | сборщик или форма      | Полный текст поста                                                     |
| `event_date`         | дата `ГГГГ-ММ-ДД`                  | для `published` да | сборщик или форма      | `2026-10-18`. Не нашли дату — не подставлять дату публикации           |
| `start_time`         | время `ЧЧ:ММ`                      | нет                | сборщик или форма      | `18:00`. В 16 из 50 объявлений времени нет                             |
| `end_date`           | дата `ГГГГ-ММ-ДД`                  | нет                | сборщик или форма      | Для «26–30 октября»                                                    |
| `end_time`           | время `ЧЧ:ММ`                      | нет                | сборщик или форма      | `19:30`                                                                |
| `location`           | строка                             | нет                | сборщик или форма      | `ул. Карпова, 4`; «Онлайн» — тоже место                                |
| `organizer`          | строка                             | да                 | сборщик или форма      | Для ВК — название сообщества                                           |
| `original_post_link` | ссылка                             | для ВК да          | сборщик                | `https://vk.com/wall-44845822_52494` — кнопка «Подробнее во ВКонтакте» |
| `image_url`          | ссылка                             | нет                | сборщик                |                                                                        |
| `contact`            | строка                             | для формы да       | форма                  | Хранится в базе, в API не отдаётся                                     |
| `created_at`         | дата и время                       | да                 | база                   |                                                                        |

## Категории

Список утверждается на планировании и согласуется с куратором.

| Код            | Название           |
| -------------- | ------------------ |
| `sport`        | Спорт              |
| `science`      | Наука              |
| `creativity`   | Культура           |
| `volunteering` | Волонтёрство       |
| `career`       | Карьера            |
| `student_life` | Студенческая жизнь |

## Пример записи в ответе API

Список (`GET /api/events`):

```json
{
  "items": [
    {
      "id": 101,
      "title": "Мастер-класс по алтимату",
      "organizer": "Спортклуб «Сибирские львы»",
      "category": { "slug": "sport", "name": "Спорт" },
      "event_date": "2026-10-18",
      "end_date": null,
      "start_time": "18:00",
      "end_time": null,
      "location": "ул. Карпова, 4",
      "original_post_link": "https://vk.com/wall-44845822_52494"
    }
  ],
  "page": 1,
  "per_page": 20,
  "total": 1
}
```

Одно мероприятие (`GET /api/events/{id}`) — те же поля плюс `description` и `image_url`.
