# web — страницы сайта

Отвечает: Селенкова Е.

Страницы собираются на сервере шаблонами Jinja2: `api/` передаёт в шаблон список мероприятий в формате `docs/event_format.md`, шаблон превращает его в HTML. JavaScript для основных страниц не нужен — фильтр по категории — это обычная ссылка `?category=sport`.

| Файл                   | Что в нём                                                 | Требование   |
| ---------------------- | --------------------------------------------------------- | ------------ |
| `templates/base.html`  | Шапка, колонка категорий, подвал — общие для всех страниц |              |
| `templates/index.html` | Лента мероприятий по датам                                | ФТ-06, ФТ-07 |
| `templates/event.html` | Страница одного мероприятия со ссылкой на пост ВК         | ФТ-08        |
| `static/style.css`     | Стили, в том числе для экрана смартфона                   | НФТ-02       |

Образец — макет https://event-calendar-tpu.poehali.ws/. Сгенерированный конструктором код не переносим, верстаем по образцу.

Проверить в шаблонах:

- у мероприятия нет времени — не показывать «None» или «00:00»;
- многодневное мероприятие — показывать диапазон дат;
- «Онлайн» вместо адреса;
- пустая лента — «Пока нет мероприятий».
