# web — фронтенд календаря ТПУ

Отвечает: Селенкова Е.

React + TypeScript + Vite. Интерфейс повторяет [интерактивный макет](https://event-calendar-tpu.poehali.ws/): зелёная палитра, Manrope/Unbounded, категории, лента по дням и календарь. Данные берутся из нашего FastAPI, без облачных функций poehali и без автоматической подстановки моков. Старые Jinja-шаблоны из неполного экспорта удалены: сервер уже раздаёт SPA из `web/dist`.

## Требования

- Node.js 22.x, не ниже 22.22.2, npm.
- Python и зависимости из корневого `requirements.txt` для API.
- Созданная база: `python -m db.init_db` из корня репозитория.

Фронтенду не нужен ключ VK. Сборщик запускается отдельно и пишет в ту же базу. Контракт запросов: [docs/api.md](../docs/api.md).

## Разработка

Первый терминал, из корня репозитория (после установки Python-зависимостей и активации venv):

```bash
python -m db.init_db
# Только для чистой локальной базы, если нужны примеры:
python -m db.seed_test
python -m uvicorn api.main:app --reload
```

Второй терминал:

```bash
cd web
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173. Страницы меняются без перезапуска. Все запросы `/api/*` Vite проксирует в http://127.0.0.1:8000; менять CORS не нужно. Порт 5173 фиксирован: если занят, остановите старый процесс или укажите `npm run dev -- --port 5174`.

Если API работает на другом порту, скопируйте `web/.env.example` в `web/.env` и поменяйте `API_PROXY_TARGET`. После изменения перезапустите Vite. Эта настройка читается только сервером разработки/preview и не попадает в JS сборки. Не добавляйте VK_TOKEN и DATABASE_URL в переменные с префиксом VITE_: они публичные.

## Production-сборка

Из `web`:

```bash
npm ci
npm run build
```

Сначала TypeScript проверяет типы, затем Vite создаёт `web/dist/index.html` и файлы с хешами в `web/dist/assets/`. Перезапустите FastAPI **после** сборки: при старте он проверяет наличие `dist/index.html`.

```bash
# Из корня репозитория:
python -m uvicorn api.main:app
```

Сайт и API: http://127.0.0.1:8000. Прямые ссылки `/event/12`, `/calendar`, `/submit`, `/guide` открываются через `api/frontend.py`. Для отдельного статического хостинга нужны fallback на `index.html` и прокси `/api/*` к FastAPI. Сам `dist` серверной части не содержит.

`npm run preview` (из `web`) позволяет проверить сборку на http://127.0.0.1:4173 с тем же прокси к API. Это локальная проверка, не production-сервер. Размещение на Vercel и база Neon — отдельная задача; учётных данных хостинга в коде нет.

## Проверки

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

Тесты Vitest + Testing Library выполняются в jsdom: запросы и ошибки API, пагинация, поиск вместе с категорией, отмена устаревших запросов, карточка, календарь, отправка заявки, 422, даты Томска и переходы между месяцами. Это не проверка внешнего вида в настоящем браузере.

Интеграция с сервером, из корня:

```bash
python -m pytest
```

## Структура и поведение

- `index.html`, `src/main.tsx` — точка входа SPA.
- `src/App.tsx` — маршруты и экраны, адаптивная навигация, формы.
- `src/api.ts` — типы контракта и относительные запросы `/api`. Коды категорий используются из API напрямую: `creativity`, `volunteering`, `student_life` и остальные; преобразование старых кодов макета не требуется.
- `src/dates.ts` — даты и подписи по Томску (UTC+7), диапазоны через границы месяцев/лет.
- `static/style.css` — все стили, включая мобильные экраны, focus и reduced motion; импортируется точкой входа и входит в сборку. Tailwind/CDN для стилей не нужны.
- `public/` — favicon и будущие статические файлы.

Лента загружает страницы по 20 событий, кнопка «Показать ещё» сохраняет предыдущие. Поиск и категория хранятся в URL. Календарь загружает **все** страницы месяца по 100 записей, включая прошедшие дни; многодневное мероприятие видно в каждом дне диапазона. Текущее число обновляется при переходе суток по Томску.

Отсутствующие время, адрес и VK-ссылка не выдумываются. Без ссылки кнопка ВКонтакте скрыта. Описание выводится текстом, а не HTML. Ошибки сети и сервера показываются с кнопкой повтора. Запросы ограничены 15 секундами, устаревшие чтения отменяются.

Форма отправляет `POST /api/submissions`, показывает полевые ошибки 422, сохраняет введённые данные при ошибке и после 201 показывает номер заявки. До модерации заявка не видна в ленте; контакт не публикуется. Админка `/admin` поддерживает вход, очередь по статусам, исправление полей, публикацию и отклонение. Сессия хранится в HttpOnly cookie и базе; изменения защищены CSRF-токеном. Создать первого администратора: `python -m db.create_admin semyon` из корня.

`node_modules`, `dist`, `.env` не коммитятся; `package-lock.json` коммитится для воспроизводимой установки через `npm ci`.

Развёртывание с нуля: [Vercel + Neon](../docs/deployment.md).
